# Cycle Start Studios

The website for [cyclestartstudios.com](https://cyclestartstudios.com) — a few games you can play free in
your browser, on a phone or a desktop. No ads, no purchases, no timers.

## Play

| Game | What it is |
|------|------------|
| [Bloom](https://cyclestartstudios.com/games/bloom/) | A quiet game about a creature in a deep sea. |
| [Pocket Dungeons](https://cyclestartstudios.com/games/pocket-dungeons/) | A cozy turn-based isometric pixel-art RPG. |
| [Pocket Dice](https://cyclestartstudios.com/games/pocket-dice/) | A realistic 3D dice tray. |
| [Neon Horde](https://cyclestartstudios.com/games/neon-horde/) | A synthwave lane-runner horde shooter. |
| [Catdoku](https://cyclestartstudios.com/games/catdoku/) | Two logic puzzles on one neon grid. |
| [Snap Shuffle](https://cyclestartstudios.com/games/snap-shuffle/) | A synthwave picture puzzle. |
| [Traffic Jam](https://cyclestartstudios.com/games/traffic-jam/) | A synthwave sliding-block puzzle. |

Each game is developed in its own repository. This one holds the site itself and a copy of each game's
playable web build.
